🧱 Arkanoid 3D — трёхмерный арканоид
Классический арканоид в трёхмерном пространстве! Управляйте платформой по двум осям, отбивайте мяч и разрушайте блоки, расположенные в объёмной сетке.
Реализован на 7 языках программирования для демонстрации алгоритмов работы с 3D-массивами, физикой и интерактивным вводом.

🧠 Концепция
Arkanoid 3D — это модификация знаменитой игры, перенесённая в третье измерение. Игрок управляет платформой, которая движется по горизонтали (X) и глубине (Z), отбивая мяч в трёхмерном пространстве. Блоки расположены слоями, создавая объёмную стену. Особенности:

✅ Трёхмерное поле — сетка блоков имеет ширину, высоту и глубину.

✅ Управление платформой — движение по двум осям (X и Z) с помощью клавиш.

✅ Мяч — летит в 3D-пространстве, отражаясь от стен, платформы и блоков.

✅ Блоки — разрушаются при попадании, каждый слой имеет разную прочность.

✅ Счёт и уровни — очки за каждый разрушенный блок, переход на следующий уровень после очистки поля.

✅ Визуализация — псевдо-3D вид (изометрическая проекция) в консоли.

🚀 Как запустить
Для каждой версии используются стандартные библиотеки или минимальные зависимости. Установите их и запустите.

Python
bash
pip install keyboard  # для неблокирующего ввода
python arkanoid3d.py
C++
bash
# Для Linux требуется ncurses (sudo apt install libncurses-dev)
g++ -std=c++17 arkanoid3d.cpp -o arkanoid3d -lncurses
./arkanoid3d
Java
bash
javac Arkanoid3D.java && java Arkanoid3D
C#
bash
dotnet run
Go
bash
go mod init arkanoid3d
go get github.com/eiannone/keyboard
go run arkanoid3d.go
Rust
bash
cargo new arkanoid3d
cd arkanoid3d
cargo add termion rand
cargo run
JavaScript (Node.js)
bash
npm install keypress
node arkanoid3d.js

🔮 Расширенные функции
Бонусы — расширение платформы, ускорение мяча, дополнительные жизни.

Уровни сложности — с каждым уровнем блоки становятся прочнее.

Рекорд — сохраняется в файл.

Звуковые эффекты (в некоторых версиях) — через системный beep.
